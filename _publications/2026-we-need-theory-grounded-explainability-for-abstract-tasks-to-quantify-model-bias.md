title: We need theory-grounded explainability for abstract tasks to quantify model bias
description: Explanations of abstract classifications need a clear theoretical reference. This position argues
  for evaluating model explanations against validated, context-specific constructs to make model bias measurable.
why: Explaining a prediction about an abstract idea requires more than highlighting a patch of an image. This
  position argues that explanations should connect to well-defined, context-specific concepts. That connection
  matters if researchers want to measure model bias rather than merely produce explanations that look plausible.
